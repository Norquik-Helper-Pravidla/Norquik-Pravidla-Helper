# Norquik-Pravidla-Helper
Pokud chceš být Helper tak by jsi mněl znát pravidla.
<header>
  <h1>Norquik – Pravidla Helperů</h1>
</header>

<main>
  <h2>1. Chovej se jako helper</h2>
  <ul>
    <li>Buď aktivní, přátelský a ochotný pomáhat.</li>
    <li>Nepovyšuj se nad hráče – helper ≠ šéf.</li>
  </ul>

  <h2>2. Nepoužívej pravomoci pro zábavu</h2>
  <ul>
    <li>Příkazy jako /mute, /kick používej s rozumem.</li>
    <li>Netp se za hráči bez jejich souhlasu (pokud to není nutné).</li>
  </ul>

  <h2>3. Konflikty řeš s klidem</h2>
  <ul>
    <li>Nereaguj agresivně – zůstaň nad věcí.</li>
    <li>Problémy předej vedení, pokud jsou složité.</li>
  </ul>

  <h2>4. Spolupracuj s týmem</h2>
  <ul>
    <li>Buď aktivní na Discordu a dávej vědět, když budeš offline.</li>
    <li>Pomáhej i ostatním helperům.</li>
  </ul>

  <h2>5. Důvěra a zodpovědnost</h2>
  <ul>
    <li>Nezneužívej pozici helpera ani žádné informace.</li>
    <li>Při porušení pravidel můžeš být z týmu odebrán.</li>
  </ul>

  <p><strong>📌 Helper je zástupce serveru. Pokud nechceš pomáhat, helper není pro tebe.</strong></p>
</main>
